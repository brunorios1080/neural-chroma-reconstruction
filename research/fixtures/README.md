# Local protocol fixtures

The PNG files in `lossless/` are deterministic procedural images generated by
`scripts/generate_research_fixture.py`. Their train, validation, and test hashes
are disjoint. They exercise sharp color boundaries, diagonals, stripes, curves,
and smooth gradients.

They exist only to make the manifest, ablation, metric, profiling, codec, and
qualitative-output paths locally auditable. Results on these fixtures are not
scientific evidence and must not be copied into the paper's result tables.

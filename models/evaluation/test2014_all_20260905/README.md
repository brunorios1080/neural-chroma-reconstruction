# COCO test2014 selected weights

These are the 21 frozen checkpoints used for the 2026-09-05 COCO test2014 comparison. See `campaign.json` for each selected source checkpoint and `comparison.csv` or `comparison.json` for results. Four Prism selected weights differ from the later `best.pth` files in `models/experiments/`, so retaining this directory preserves the exact evaluation inputs.

The test image IDs are listed in [`research/manifests/ids/coco_test2014_test.txt`](../../../research/manifests/ids/coco_test2014_test.txt). No source images or dataset archive are included.
